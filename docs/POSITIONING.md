# EAH — Positioning (مقفول)

**آخر تحديث:** 2026-11-24
**الحالة:** 🔒 مقفول — لا تغيير بدون موافقة صريحة
**الغرض:** منع أي انحراف في التموضع أو في UI copy مستقبلاً.

---

## ما EAH هو

**دليل اكتشاف محلي + تواصل + طلبات بسيطة.**

منصة تُمكّن صاحب النشاط من:
- صفحة احترافية كاملة (صور، ساعات، GPS، أرقام تواصل، عروض، تقييمات)
- استقبال طلبات بسيطة من الزوار
- إحصائيات (زيارات، اتصالات)
- QR code + شارة توثيق

وتمكّن العميل من:
- اكتشاف الأنشطة في منطقته (شبين القناطر → القليوبية → الدلتا)
- التواصل المباشر (هاتف/واتساب)
- إرسال طلب بسيط
- قراءة تقييمات موثقة

## ما EAH ليس (حرج)

❌ **ليس متجرًا إلكترونيًا** (e-commerce store)

| الميزة | موجود في EAH؟ |
|---|---|
| صفحة نشاط احترافية | ✅ |
| صور + معرض + غلاف | ✅ |
| ساعات + GPS + عنوان | ✅ |
| أرقام تواصل | ✅ |
| استقبال طلبات بسيطة | ✅ |
| تقييمات + شارة توثيق | ✅ |
| إحصائيات + QR | ✅ |
| سلة شراء (cart) | ❌ |
| دفع إلكتروني | ❌ |
| شحن وتوصيل | ❌ |
| إدارة مخزون | ❌ |
| كوبونات خصم | ❌ |
| تقارير مبيعات متقدمة | ❌ |
| CRM | ❌ |
| تعدد منتجات داخل نشاط واحد | ❌ |

**المنصات التي تقدم متجرًا كاملاً:** سلة، زد، شوبيفاي، EasyOrders، ExpandCart.
**EAH ليس منافسًا لها.** المنافس الحقيقي: Google Maps، Facebook Pages، دليل محلي تقليدي.

## اللغة المسموحة والممنوعة في UI copy

### ✅ مسموح
- نشاط / صفحة النشاط
- دليل اكتشاف / اكتشف
- تواصل / طلب (بسيط)
- عرض / تقييم / موثق

### ❌ ممنوع (حتى لو بدا جذابًا)
- متجر / store / shop
- سلة / cart
- دفع إلكتروني
- شحن
- منتجات (بمعنى كتالوج متعدد)
- تاجر إلكتروني

**سبب المنع:** وعود لا تُطابق الواقع = خيبة أمل + فقدان ثقة + شكاوى + تسريب سمعة.

## الصياغة الرسمية لصاحب النشاط

> هديك صفحة احترافية كاملة لنشاطك — مجلة اكتشافية للزوار فيها كل تفاصيلك: صور، ساعات، موقع، أرقام تواصل، عروض، وتقييمات حقيقية. الزائر يقدر يتواصل معاك مباشرة أو يبعتلك طلب من المنصة. كل هذا مجاناً.

دقيقة + جذابة + واضحة. لا وعود كاذبة.

---

## الصياغة الرسمية للعميل

> اكتشف الأنشطة في منطقتك، اقرأ تقييمات حقيقية، تواصل مباشرة، أو ابعت طلب — كل ده في مكان واحد.

## استراتيجية التوسع (مقفولة — تدريجية)

| المرحلة | النطاق | المدة | الهدف |
|---|---|---|---|
| 1 (الآن) | شبين القناطر | 3-6 أشهر | 50 نشاط ممتاز + 100 عميل |
| 2 | القليوبية (شبين + بنها + قليوب) | 6-12 شهر | 200-500 نشاط |
| 3 | الدلتا (طنطا، المنصورة، الزقازيق) | 12-24 شهر | 1000+ نشاط |

**قاعدة:** لا تتوسع في الفئات قبل أن تتوسع جغرافياً. عمق > عرض.
