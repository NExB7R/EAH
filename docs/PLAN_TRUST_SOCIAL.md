## 1. Business Trust — Trust DNA

**5 محاور (بصمة رادار):**
- Response (سرعة الرد)
- Quality (التقييمات)
- Volume (الطلبات)
- Freshness (حداثة البيانات)
- Community (التفاعل)

**الترند = Trust (60%) + Velocity (20%) + Recency (20%)**

## 2. Customer Reputation

### Trust Score (0-100)
يبدأ 100. بينزل بالمخالفات:

| Score | الحالة | النتيجة |
|-------|--------|---------|
| 75-100 | طبيعي | كل حاجة |
| 50-74 | مراقبة | إشعار |
| 25-49 | تحذير | ممنوع يقيّم |
| 10-24 | مقيّد | يتصفح بس |
| 0-9 | موقوف | مراجعة يدوية |

**بيتحرك:**
- تقييم مقبول → +5
- تقييم مرفوض → -10
- بلاغ صحيح → -20
- طلب مكتمل → +2
- خمول 60 يوم → -1 أسبوعياً (بحد -20)

**الضمانات:**
- شفافية كاملة (كل سبب بتاريخ)
- إشعار قبل التقييد 48 ساعة
- Appeal → مراجعة يدوية
- صفر بان أوتوماتيك دائم

### نظام الجاتا — Wanted Level (EAH Style)
بدل "عدد التبليغات" — مؤشر بصري:
- ⭐ (1 نجمة) = تبليغ واحد صحيح — ملاحظة
- ⭐⭐ (2 نجوم) = تبليغين — مراقبة
- ⭐⭐⭐ (3 نجوم) = تحذير — ممنوع تقييم
- ⭐⭐⭐⭐ (4 نجوم) = مقيّد — يتصفح بس
- 💀 (خطر) = موقوف — مراجعة يدوية

النجوم تختفي بعد 30 يوم نظيف.

| Level | اللقب |

## 3. البحث (Truecaller-style)

**بحث بالرقم الكامل (11 رقم) فقط:**
- ✅ مسجل → الاسم + الصورة + قوة الحساب + المستوى
- ❌ مش مسجل → "الرقم ده مش مسجل"
- ⚠️ ناقص → "الرقم ناقص"
- ⚠️ غلط → "الرقم مش صح"

**بحث بالاسم:** ممنوع.
**بحث جزئي:** ممنوع.

**الرقم نفسه مش بيتعرض.** اللي بيتعرض: الاسم + القوة.

---

## 4. البروفايل (بعد البحث)

**يظهر:**
- الاسم + الصورة
- Trust Ring (لون حسب Score)
- Level + Badges
- عدد التقييمات المقبولة
- Wanted Level (نجوم الجاتا)
- المفضلات (عدد + أسماء)
- المتابعة (عدد + أسماء)
- آخر 5 تقييمات

**مفيش:** بوستات، لايكات، كومنتات، شات، رسائل، متابعة مباشرة.

---

## 5. العميل يستفيد إيه؟ (يثبّت التطبيق)

1. بديل جروبات الفيسبوك — 3 ثواني تلاقي
2. طلب مباشر بدون وسيط — بدون عمولة
3. صوت حقيقي — التقييم يأثر
4. مكانة اجتماعية — بروفايل حقيقي
5. عروض حصرية + أولوية إشعار

**الإشعارات الذكية = المفتاح**

## 9. نظام الإعلانات

### العدّاد
- **الدقة:** بالدقايق
- **الأعمدة:** total_minutes / used_minutes / remaining_minutes
- **التجميد:** لما يوقف، العدّاد بيتوقف
- **العميل يشوف:** "فاضل: 4 أيام و 12 ساعة و 30 دقيقة"

### الإيقاف
- المعلن يقدر يوقف في أي وقت
- الوقت بيتجمّد
- يرجع → يكمّل من نفس النقطة
- **حد أقصى:** 7 أيام (بعدها إنت تقرر)
- **مفيش طابور، مفيش تبديل** — الدفع يدوي

### الإشعارات
| المستوى | إعادة؟ |
|---------|--------|
| 🔴 حرج | كل 12 ساعة |
| 🟠 مهم | مرة بعد 12 ساعة |
| 🟡 عادي | مرة واحدة |

## 11. الخصوصية

### عميل عادي (مجاني)
- الاسم: حقيقي / كنية / الاتنين
- الصورة: **إلزامية** (أو مفيش صورة خالص)
- المتابعات: عامة / محدودة / مخفية
- المفضلات: عامة / محدودة / مخفية
- **له لينك بروفايل**
- الرقم: مخفي

### عميل مدفوع (Ghost)
- الاسم: حقيقي / كنية / الاتنين / **مجهول**
- الصورة: **اختياري**
- **مفيش لينك بروفايل**
- **شارة ذهبية**
- الرقم: مخفي

### البحث بالرقم الكامل
| النوع | النتيجة |
|-------|---------|
| عميل عادي | "مسجل" + البيانات المختارة |
| عميل مدفوع | "مسجل — حساب خاص" (بدون بيانات، بدون لينك) |
| **مفيش اختفاء كامل** | الرقم دايماً بيقول "مسجل" |

## 12. التعليقات والبروفايل

## 13. أرقام النشاط

- مينفعش تتسجل كحساب عميل
- لو حد حاول → "الرقم ده مربوط بنشاط" (بدون ذكر اسم النشاط)
