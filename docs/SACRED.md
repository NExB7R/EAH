## 0. ليه الملف ده؟

فيه حاجات في EAH مش قابلة للنقاش:
- الهوية (الألوان + الخطوط + الشعار)
- السلوغان والهوك
- المبادئ الأساسية (مجاني للعميل، بدون عمولة)
- الملفات المقدسة

دي اللي بتخلي EAH مميز. لو اتغيرت، EAH بيبقى منصة تانية.

## 1. الهوية البصرية (مقدسة)

### 1.1 الألوان

الخلفية:
- bg: #07020D (أسود بنفسجي عميق)

البنفسجي:
- purple-1: #9D4EDD (هادئ)
- purple-2: #A855F7 (نيون)
- purple-3: #C77DFF (فاتح)

الذهبي:
- gold-1: #E8C79A (هادئ)
- gold-2: #F5D9A7 (فاتح)

الثانوية:
- teal: #55E7D1 (للنجاح)
- orange: #FDBA74 (للترند)
- red: #FCA5A5 (للتحذير)

القاعدة:
- البنفسجي = أساسي
- الذهبي = accent (للمميزين + العناوين)
- Teal = للنجاح فقط
- Orange = للترند فقط
- Red = للتحذير فقط

ممنوع:
- أي لون خارج القائمة
- تغيير القيم
- إضافة تدرجات جديدة

### 1.2 الخطوط

- الرئيسي: Cairo Variable
- العرض: Tajawal Variable
- التوقيع: Brush Script MT / Segoe Script

ممنوع:
- Poppins, Inter, Roboto
- أي خط غير معرّف
- أكتر من 2 خطوط

### 1.3 الستايل العام

- Dark-only - لا light mode أبداً
- نيون ناعم - طبقة واحدة، بدون توهج عالي
- بدون backdrop-filter على الكروت
- بدون animations مستمرة
- انسيابية - transitions 180-240ms
- الروح: Linear x Vercel x Stripe x Apple

## 3. المبادئ الأساسية (مقدسة)

### 3.1 للعميل
- مجاني بالكامل - صفر رسوم
- بدون عمولة على الطلبات
- بدون إعلانات مزعجة

- لا نبيع بيانات المستخدمين
- لا نستخدم dark patterns
- لا نضغط على الترقية
- الشفافية دايماً

### 3.4 للقضية
- فلسطين في القلب - دايماً
- 2% من الدخل لصندوق فلسطين
- الموقف ثابت - لا يتغير

- scale > 1.1

- fade in (200-300ms)

- hover transforms (180-240ms)

## 14. الالتزام

كل AI أو مطور يشتغل على EAH يلتزم بـ:

- الأدوار الوحيدة هي الأدمن/البايع/المشتري. الزائر حالة وصول غير مسجلة وليس دورًا رابعًا. لا تستخدم مسميات بديلة ولا تنشئ دورًا إضافيًا. واجهة المستخدم بالعربية فقط وباتجاه RTL. حافظ على القيم التقنية الداخلية دون تغيير عشوائي، وافصل الدور عن الملكية وحالات الحساب والنشاط والاشتراك والتحقق والنشر؛ راجع `docs/ROLES_MATRIX.md`.
- احترام الملفات المقدسة
- عدم تعديل الممنوعات
- السؤال قبل أي تعديل
- الحفاظ على الهوية
- الحفاظ على السرعة
- الحفاظ على الأمان
- الحفاظ على القضية

مخالفة أي بند -> إيقاف فوري + مراجعة.
