# EAH — Handoff

## الحالة التشغيلية المعتمدة — 2026-11-20

> هذه الحالة أحدث من الملاحظات التاريخية أدناه، وتُقدَّم عليها عند التعارض.

- الفرع المعتمد للعمل هو `main` مباشرة. لا تنشئ فروع اختبار أو فروع عمل غير لازمة، ولا تستخدم PR/branch flow كشرط افتراضي.
- الأدوار المسجلة ثلاثة فقط: الأدمن (`super_admin`)، العميل (`customer`)، والتاجر (`merchant`). الزائر حالة وصول وليس دورًا رابعًا. استخدم هذه المسميات في النصوص الظاهرة للمستخدم، مع الحفاظ على المفاتيح التقنية الحالية.
- يمكن للأدمن إنشاء نشاط دون مالك؛ ربط مستخدم موجود اختياري ولا يتطلب رقم هاتفه الشخصي. إنشاء النشاط يبدأ كمسودة، ولا يظهر في البحث أو الصفحة العامة قبل النشر الصريح.
- لا تُجرَ أي كتابة أو migration أو seed أو رفع ملفات على Supabase الإنتاجي. اختبارات قواعد البيانات تتطلب قاعدة QA منفصلة، ويجب أن يظل فحص CI رافضًا لمعرف مشروع الإنتاج.
- لا تنفّذ نشرًا أو تغيّر إعدادات Vercel أو تعيد تشغيل workflow دون مراجعة مبررة. وفق الحالة المسجلة، Vercel متوقف حتى 2026-12-15 بسبب حدود موارد الخطة؛ لا تعتبر أي نشر قديم دليلًا على صلاحية آخر `main`.
- آخر commit معروف على `main`: `5f7f50573d3b56b990dae7cdd44dd57cc5811285` (`docs: sync product navigation and role terminology`). آخر نشر Vercel المسجل كان على `62e152d3a1d834416a4a307a279a9403298fb18f`، أي أقدم بـ47 commit عند المقارنة بتاريخ 2026-11-20.
- حالة فحص Vercel على آخر commit كانت `failure` بسبب حظر الحساب/النشر؛ لا يوجد في نتيجة فحص commit الأخير ما يثبت فشل TypeScript أو الاختبارات أو build. كما أن commit الأخير توثيقي وتستثنيه مسارات workflow من التشغيل.
- لا تدّعِ اجتياز E2E قبل إثبات المسار كاملًا على بيئة QA معزولة: إنشاء نشاط بلا مالك ومع مالك اختياري، رفع الشعار والغلاف، النشر، ظهوره في البحث، وفتح الصفحة العامة.
- تقرير كل جلسة يجب أن يميّز بين الفحوص المنفذة فعليًا، والفحوص غير المتاحة، والمشكلات المؤكدة، وما لم يُختبر بصريًا أو على قاعدة QA.

## 🚨 قواعد تقنية صارمة

### ⛔ Hard NOs

| ممنوع | السبب |
|---|---|
| `npm run build` محليًا | SIGILL على الجهاز |
| `npm test` (كامل) | بطيء. استخدم `npx vitest run <file>` |
| `nano` | بيعلق الترمنال |
| heredoc > 50 سطر | بيتقطع. قسّم أجزاء |
| خطوط Poppins/Inter/Roboto | خطوط EAH: Tajawal + Cairo |
| `git push --force` | يمسح شغل |
| تعديل migrations قديمة | اعمل جديدة |

### 🔒 RPCs محمية (service_role فقط)

- `get_multi_account_ips`: REVOKED من PUBLIC + anon + authenticated
- `find_by_phone`: REVOKED من anon/authenticated (service بعد rate-limit)
- `is_phone_registered`: service_role فقط
- `can_interact`: authenticated (للتحقق من standing)
- `check_trigger_status`: authenticated (للـ health)

### 🎨 قواعد التصميم

- خطوط: Tajawal + Cairo + Great Vibes فقط
- Dark theme فقط، لا light mode
- RTL كامل: `dir="rtl"` على html
- Design tokens: `var(--purple-2-20)` بدل rgba يدوي
- Mobile-first: ابدأ من 320px

### 🗄️ قواعد Database

- RLS إجباري على أي جدول جديد
- service_role في Server Actions فقط
- Demo data يبدأ بـ `demo-` أو `eah-qa-test-`
- CHECK constraints للحقول الحساسة
- Triggers لازم تتحقق من أعمدة الجدول

### ⚙️ Vercel

- كل push = 1-2 build min
- `npm ci` على Vercel يحتاج package-lock متزامن
- Build fail = rollback فوري
- Env vars في Dashboard فقط

### 🧪 Testing

- `npx vitest run <file>` فقط
- RLS tests في web/supabase/tests/
- E2E في web/e2e/ (Playwright على CI)
