## المشاكل التي حدثت (Dروس)

### 1. regex شامل كسر 5 ملفات
**الخطأ:** `s.replace(r"accepts_whatsapp_orders\s*[,:]", "")` — حذف `:` من `accepts_orders: ...` ونتج `accepts_orders: : ...`

**الإصلاح:** Rollback + patch لكل ملف على حدة

**القاعدة الجديدة:** لا regex شامل. patch ملف واحد، تحقق، انتقل للتالي

### 2. `EXIT=0` misleading في tsc
**الخطأ:** `npx tsc --noEmit 2>&1 | head -20; echo "EXIT=$?"` — `$?` يعكس exit code `head` (دائمًا 0)

**الإصلاح:** `npx tsc --noEmit > /tmp/tsc.log 2>&1; echo "REAL_EXIT=$?"; tail -5 /tmp/tsc.log`

**القاعدة:** استخدم `REAL_EXIT` دائمًا

### 3. migration بنيته JSON خاطئ
**الخطأ:** `'[...]'::jsonb` — placeholder في SQL ليس JSON

**القاعدة:** في SQL، JSON = `'["a","b"]'::jsonb`

### 4. features ناقصة بعد UPDATE
**المشكلة:** `featured_monthly` لم يكن فيه `whatsapp_orders`، فالـ UPDATE لم يمسه → بقي 4 features بدل 9

**الإصلاح:** UPDATE مباشر بـ 9 features جديدة

**القاعدة:** بعد كل UPDATE على JSONB، تحقق من `jsonb_array_length(features)`

### 5. Dependency على عمود قبل حذفه
**المشكلة:** v9 حذف `accepts_whatsapp_orders` قبل تحديث الكود

**الإصلاح:** Rollback + v10 (إضافة `accepts_online_orders` بجانب القديم)

**القاعدة:** أضف الجديد → حدّث الكود → احذف القديم (3 خطوات، ليس خطوة واحدة)
