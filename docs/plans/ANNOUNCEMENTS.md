# EAH — خطة: إشعارات المسؤول (Announcements)

> الإشعار الرسمي من إدارة EAH. آخر تحديث: 2026-10-02

---

## الفكرة

المسؤول (NourEldin) يبعت رسالة تظهر في إشعارات المستخدمين، **بشكل مميز** يوحي إنها من صاحب المنصة نفسه — مش من نظام آلي.

---

## الاستهداف

| النوع | مثال |
|-------|------|
| **مستخدم معين** | إشعار شخصي لـ user_id |
| **كل العملاء** | role = customer |
| **كل الأنشطة** | role = merchant |
| **كل المستخدمين** | الجميع |
| **باقة معينة** | subscription = premium / growth / partnership |
| **حالة معينة** | phone_verified / trust_score > X / Streak > Y |

---

## الشكل المميز

- **هوية بصرية خاصة** — ذهبي + خلفية مميزة (مش بنفسجي عادي)
- **اسم المسؤول** ظاهر (NourEldin B7R) + التوقيع
- **شارة "من الإدارة"** أو "رسالة رسمية"
- **مش قابل للحذف** بدون قراءة
- **Badge مختلف** — مش النقطة الحمرا العادية

---

## التنفيذ المقترح

### DB
- جدول جديد: `announcements`
  - id, title, body, target_type, target_value, priority, created_at, expires_at
- جدول: `announcement_views` (user_id, announcement_id, read_at)

### Admin UI
- `/admin/announcements`
  - إنشاء رسالة (title + body + target)
  - معاينة قبل الإرسال
  - إحصائيات (وصل → قرأ)

### User UI
- تظهر في `/account/notifications` بلون ذهبي مميز
- **Modal أول ما يفتح** لو priority = high
- Badge مختلف في الهيدر
