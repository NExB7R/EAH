# EAH — AI AGENT PLAN

> الوكيل الذكي للمنصة. آخر تحديث: 2026-09-30

---

## الفكرة

وكيل ذكي (مش بوت) — يفهم المنصة كلها، يبحث، ينفذ، ويحوّل لك.

- **مجاني:** Recourse (مفتوح المصدر MIT)
- **آمن:** self-hosted، مفيش API خارجي
- **في كل مكان:** Widget عائم على كل الصفحات
- **يلبي أي مستخدم:** حتى اللي مش بيعرف يقرأ ويكتب (بالصوت)

---

## 3 طبقات

### 1. قاعدة المعرفة (RAG)
- وثائق docs/ تتحول لـ embeddings
- تتخزن في Supabase + pgvector
- الوكيل يدور ويجاوب من معلوماتك بس

### 2. البحث الدلالي
- كل نشاط يتحول لـ embedding
- "عايز أكل" = "مطعم" تلقائياً
- يدور بالمعنى مش بالكلمة

### 3. الأدوات المخصصة
| الأداة | الوظيفة |
|--------|---------|
| search_businesses | بحث بالاسم/التصنيف/المسافة |
| search_by_phone | بحث بالرقم الكامل |
| get_business_details | تفاصيل نشاط |
| check_subscription | باقة العميل |
| get_ad_slots | المساحات الإعلانية |
| create_support_ticket | فتح تذكرة |
| escalate_to_admin | تحويل لك |
