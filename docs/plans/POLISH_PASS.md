# EAH — خطة ما بعد الإطلاق (Polish Pass)

> تنفّذ لما نخلّص كل الصفحات + اختبار. بنمر على كل صفحة صفحة.

## 1. المسافة
- العميل يشوف المسافة بالظبط (مش تقديري)
- الشرط: النشاط حاطط location + العميل وافق على geolocation
- الأماكن: الكارد + صفحة النشاط
- الصيغة: أقل من 100م → "50 م"، أقل من 1كم → "800 م"، أكبر → "1.2 كم"
- لو ناقص شرط → مفيش رقم (مش "—")

## 2. الكارد الموحد
العناصر الإجبارية:
1. صورة النشاط (WmImage + fallback)
2. اسم النشاط
3. الهوك / السلوغان
4. التقييم (رقم + عدد المراجعات)
5. شارة توثيق النشاط فقط (is_verified)؛ نقاط المشاركة لا تظهر على الكارد العام
6. شارة "مفتوح"
7. المسافة (لو الشرطين متوفرين)
8. المنطقة
9. عدد العروض
10. شارة "مميز" (للمميزين فقط)

المعايير: سريع، خفيف، متجاوب (320px → 4K)، متماسك.

## 3. فخامة المميزين
- إطار ذهبي ناعم + shimmer مرة واحدة عند الظهور
- شارة ذهبية على الصورة
- صفحة النشاط: Hero ذهبي + Tabs بحدود ذهبية
- الترند: أيقونة TrendingUp + إطار برتقالي
- القاعدة: الفخامة = تفاصيل صغيرة، مش أنيميشن كتير

## 4. الـ Nav
- شريط أفقي بأيقونات لكل الأقسام
- ديسكتوب: Icon + tooltip
- موبايل: Icon + كلمة صغيرة (font-size 0.6rem)
- الأيقونة النشطة: بنفسجية + glow + scroll تلقائي
- صفر animations مستمرة

## 5. السمعة والتوثيق
- is_verified → شارة توثيق واضحة، والتقييم/عدد التقييمات والطلبات المكتملة منفصلة
- trusted → ShieldCheckIcon بنفسجي
- new → SparkleStarIcon رمادي
- على الكارد: صغير أعلى الصورة
- على صفحة النشاط: كبير تحت الاسم

## 6. قاعدة التنفيذ
- صفحة صفحة
- نقيس قبل + نعدّل + نقيس بعد
- commit منفصل لكل صفحة
- ممنوع تعديل أكتر من صفحة في commit واحد
