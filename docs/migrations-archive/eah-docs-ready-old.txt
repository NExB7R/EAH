## 4. الميزات الأساسية

### 4.1 للعميل

**الاكتشاف:**
- بحث ذكي باللهجة المصرية
- بحث صوتي (Voice Search)
- AI Assistant (مجاني)
- فلاتر: تصنيف، منطقة، تقييم، مفتوح حالاً، عروض
- ترشيحات شخصية
- قريب مني (5 كم)

**المعلومات:**
- صور حقيقية + منيو + فروع
- تقييمات موثقة
- أوقات عمل دقيقة

**الطلب:**
- واتساب مباشر
- بدون وسيط
- حفظ الفواتير

**التخصيص:**
- مفضلات محفوظة
- متابعة الأنشطة
- إشعارات ذكية (تحكم كامل + iOS 16.4+)
- App Badging

**المكافآت:**
- نظام نقاط
- مستويات ولاء: Bronze / Silver / Gold / Platinum / Diamond
- كوبونات حسب المستوى
- دعوات → نقاط

**PWA:**
- تثبيت على الموبايل
- iOS + Android + Desktop
- Offline-First (Level 3: full local-first)
- Push notifications

### 4.2 للتاجر

**الظهور:**
- صفحة كاملة
- ظهور مجاني
- بدون عمولة
- QR Code مخصص

**الإحصائيات:**
- زوار (يومي/أسبوعي/شهري)
- اتصالات واتساب
- مكالمات
- تقارير PDF

**إدارة النشاط:**
- تعديل مباشر
- رفع صور + منيو
- إدارة الفروع
- رد على التقييمات

**الإشعارات:**
- تقييم جديد
- رد على تقييم
- طلب جديد
- عميل جديد
- تقرير أسبوعي
- انتهاء اشتراك (3 أيام قبل) — مقفل

**المتابعة (Followers):**
- عملاء يتابعوك
- إشعار فوري عند نزول عرض
- CRM بسيط
- تصدير CSV

### 4.3 تجربة الـ 30 يوم

- 30 يوم تجربة مجانية لأي باقة
- مؤقت احترافي في لوحة التحكم
- إشعارات: 7 أيام / 3 أيام / يوم
- صفحة ترقية عند الانتهاء
- بيانات محفوظة

### 4.4 نظام التحكم الكامل

**للمميز:**
- featured_pin boolean
- featured_order int (1-10)
- featured_until date
- Rolling shuffle (seed تاريخي)

**للإعلانات:**
- status: active / paused / expired / scheduled
- start_date + end_date
- Auto-pause
- Manual pause فوري

**للباقات:**
- status: trial / active / expired / cancelled / pending
- auto-renew
- Cron يومي
- تمديد يدوي من Admin

### 4.5 نظام النقاط

**كسب النقاط:**
- تسجيل دخول يومي — 5 نقاط
- تصفح 5 أنشطة — 3 نقاط
- مشاهدة 30s+ — 2 نقاط
- كتابة تقييم — 20 نقطة
- تقييم مع صورة — 30 نقطة
- إضافة للمفضلة — 3 نقاط
- متابعة نشاط — 5 نقاط
- مشاركة على واتساب — 8 نقاط
- طلب عبر واتساب (يأكده التاجر) — 25 نقطة
- دعوة صديق (يسجل) — 30 نقطة
- دعوة صديق (أول طلب) — 100 نقطة

**المستويات:**
- Bronze: 0-499 (1x نقاط)
- Silver: 500-1,999 (1.25x + 5% خصم إعلانات)
- Gold: 2,000-4,999 (1.5x + 10% خصم)
- Platinum: 5,000-9,999 (2x + 15% خصم)
- Diamond: 10,000+ (3x + 25% خصم)

**استخدام النقاط:**
- عرض في نشاط — 500 نقطة
- كوبون 10% — 800 نقطة
- كوبون 20% — 1,500 نقطة
- توصيل مجاني — 1,200 نقطة
- ترقية مؤقتة — 3,000 نقطة

### 4.6 WhatsApp Orders (مهم جداً)

- رسالة واتساب **غير قابلة للتعديل** قبل الإرسال
- **بدون أي تلاعب** في القيم أو المحتوى
- **تأكيد من التاجر خلال 10 دقايق**
- العميل يشوف الرد (وافق/رفض) في الوقت الفعلي
- كل حاجة تتسجل (Audit Log)
- أي تلاعب: تحذير × 2 → حظر (مراجعة يدوية)

### 4.7 التقييم بعد التجربة

- إشعار بعد **ساعة من الطلب**
- المستخدم يقيّم النشاط
- التقييم يتسجل كـ "تجربة حقيقية"
- يميزه عن التقييمات العامة

### 4.8 الأقسام المقفلة

**محتوى محمي للمسجلين فقط:**
- رقم التواصل
- التعليقات
- إضافة للمفضلة
- المتابعة
- الموقع
- التواصل على فيسبوك / واتساب

**العرض:** banner واضح "سجّل عشان تستفيد"

## 3. Supabase Clients

### 3.1 Public Client
File: lib/supabase/public.ts
Used for: Public reads (businesses, offers, reviews)
Features: No cookies, cacheable
Auth: Anonymous
Use with: unstable_cache

### 3.2 Server Client
File: lib/supabase/server.ts
Used for: Auth-aware server components
Features: Reads cookies
Auth: User session
Use with: force-dynamic only

### 3.3 Service Client
File: lib/supabase/service.ts
Used for: Admin operations (bypass RLS)
Features: Service role key
Auth: Server-only
Use with: Audit-logged

### 3.4 Browser Client
File: lib/supabase/browser.ts
Used for: Client components with auth
Features: Browser session
Auth: User session
Use with: Client components only

## 4. Data Flow

### 4.1 Public Reads (Home, Explore)
Route: force-dynamic
Client: createPublicClient (no cookies)
Cache: unstable_cache at module level
Flow: Request -> cache check -> if miss: query Supabase (RLS public) -> cache + return

### 4.2 Auth-Aware Reads (Account, Merchant)
Route: force-dynamic
Client: createClient (with cookies)
Cache: No cache (user-specific)
Flow: Request -> proxy.ts session check -> query Supabase (RLS self) -> return

### 4.3 Mutations (Create, Update, Delete)
Route: API routes
Client: createClient OR createServiceClient
Cache: revalidatePath/tag after
Flow: Client submit -> validate (zod) -> rate limit -> mutation -> revalidate -> return

## 5. Caching Strategy

### 5.1 Module-Level Cache
unstable_cache with tags + revalidate
MUST be at module level, NEVER inside component

### 5.2 Route-Level Cache
export const revalidate = 120

### 5.3 Static Cache
export const dynamic = 'force-static'
Used in: /about, /terms, /privacy, /cookies, /pricing

### 5.4 No Cache
export const dynamic = 'force-dynamic'
Used in: /, /explore, /account/*, /merchant/*, /admin/*

## 6. Authentication Flow

### 6.1 Signup
1. User submits phone + password
2. Supabase Auth creates user
3. Trigger handle_new_user runs
4. Creates profile + assigns customer role
5. Returns session
6. Client stores session

### 6.2 Login
1. User submits credentials
2. Supabase Auth verifies
3. Returns session cookies
4. proxy.ts refreshes session on every request
5. Server components read user via createClient

### 6.3 Session Refresh
File: proxy.ts (not middleware.ts)

- Runs on every request
- Refreshes expired sessions
- Redirects unauthenticated from protected routes
- Injects user into request headers

### 6.4 Logout
- POST to /auth/logout
- Clears session cookies
- Redirects to /

## 12. Q&A

### 12.1 أسئلة شائعة للعميل

**س: هل المنصة مجانية؟**
ج: أيوه، 100% مجانية للعميل — بدون رسوم ولا عمولات.

**س: إزاي أطلب؟**
ج: دوس "اطلب على واتساب" — يفتح واتساب مع رسالة جاهزة. النشاط يرد خلال 10 دقايق.

**س: إزاي أكسب نقاط؟**
ج: كل تفاعل — تسجيل دخول، تقييم، مفضلة، دعوة صاحب. النقاط تتحول لعروض.

**س: ليه بعض المعلومات مقفلة؟**
ج: عشان نضمن جودة المنصة — سجّل وشوف كل حاجة مجاناً.

### 12.2 أسئلة شائعة للتاجر

**س: كام رسوم التسجيل؟**
ج: مجاناً 100%. الباقات المدفوعة اختيارية (200-1500 ج.م/شهر).

**س: بتاخدوا نسبة من الطلبات؟**
ج: لأ، صفر عمولة. كل الأرباح ليك.

**س: إزاي أستقبل طلبات؟**
ج: العميل يدق واتساب مباشرة — إنت ترد خلال 10 دقايق، تأكد أو ترفض.

**س: إزاي أظهر في المميزين؟**
ج: اشترك في باقة المميزة (200 ج.م/شهر). أول 30 يوم مجاناً.

**س: إزاي أشيل تقييم مسيء؟**
ج: أبلغ عنه — المراجعة تشوفه خلال 24-48 ساعة.

### 12.3 أسئلة تقنية

**س: المنصة بتشتغل على iPhone؟**
ج: أيوه — PWA كامل. ثبّتها على الشاشة الرئيسية وهتشتغل زي التطبيق.

**س: بتشتغل بدون إنترنت؟**
ج: جزئياً — الصفحات المشوفة قبل كده متاحة offline.

**س: الإشعارات بتوصل إزاي؟**
ج: Web Push — بعد ما تسمح بالإشعارات (iOS 16.4+ مدعوم).
