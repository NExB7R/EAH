# EAH — Competitor Analysis (2026)

## Egypt Market

### 1. Elmenus
- **Model:** Commission per order (~15-20%) + ads
- **Strengths:** Huge restaurant database, verified reviews, ordering system
- **Weaknesses:** Commission too high for small restaurants, focus on Cairo/Alex only
- **Take from:** Verified review system, user segmentation
- **EAH advantage:** Zero commission, local focus

### 2. Talabat
- **Model:** Commission + delivery fees
- **Strengths:** Fast delivery, app UX, brand
- **Weaknesses:** Coverage gaps in small cities, expensive for merchants
- **Take from:** Real-time tracking UI
- **EAH advantage:** Free listing, local

### 3. Otlob
- **Model:** Commission-based
- **Weaknesses:** Outdated UX
- **EAH advantage:** Modern, local, no commission

### 4. Waffarha
- **Model:** Coupons + commission
- **Strengths:** Discount focus
- **Take from:** Offer presentation, urgent countdowns
- **EAH advantage:** Discovery-first (not just deals)

### 5. Facebook Pages / WhatsApp
- **Model:** Free but chaotic
- **Weaknesses:** No structure, no reviews, no discovery
- **EAH advantage:** Structured discovery + reviews + search

## Global Inspiration

### Yelp (USA)
- **Take from:** Review verification, business claim flow, badges
- **Avoid:** Pay-to-win ranking

### Foursquare (Global)
- **Take from:** Place data structure, check-ins concept
- **EAH adapt:** Daily visits as gamification

### DoorDash (USA)
- **Take from:** Merchant analytics dashboard, order status flow
- **EAH adapt:** Merchant order-to-WhatsApp feature

### Meituan (China)
- **Take from:** Hyperlocal focus, community features
- **EAH adapt:** Local village-specific content

## Recommended Features to Add (Priority)

### 🔴 High Priority
1. **Real-Time Order Tracking** — customer sees status (sent → seen → accepted → delivered)
2. **Multi-merchant order notification** — same customer, multiple businesses
3. **Push to merchant on new order** — instant
4. **Business analytics** — improve with charts (Recharts)
5. **Saved searches** — customers save frequent searches

### 🟠 Medium Priority
6. **Loyalty program v2** — points → rewards (real ones)
7. **Reservation system** — for restaurants
8. **Menu photos** — structured display
9. **Area filters + maps** — visual discovery
10. **Categories hierarchy** — restaurant → pizza, grill, etc.

### 🟡 Nice-to-have

12. **Business-to-business messaging**
13. **Sponsored categories**
14. **Weather-based recommendations**
15. **Group ordering**

## What Makes EAH Unique

1. **Zero commission** — merchants keep 100%
2. **Local-first** — Shibin + 7 villages (not Cairo)
3. **Order-to-WhatsApp** — no complex ordering system
4. **Free for customers** — always
5. **AI assistant** — 24/7 help
6. **Arabic-native** — not translated
7. **PWA offline** — works without internet
