**EAH مش منصة مطاعم — دي منصة اكتشاف محلية شاملة.**

- **الشات الجديد لازم يعرف ده قبل أي قرار.**

### 2. باقة العميل المميز: **100 ج.م/شهر**
- AI شخصي + إشعارات ذكية + تحكم خصوصية كامل + تعليق مميز + بدون إعلانات

- **مكتسب بالمعايير** (Trust + نشاط + موافقة المالك)

- العادي يقدر يبقى موثق **بدون دفع**
