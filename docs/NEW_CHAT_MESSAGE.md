## مهام مفتوحة

1. معالجة Prettier على دفعات صغيرة قابلة للمراجعة، وعدم الادعاء بنجاح Quality Gate حتى ينجح Prettier فعليًا.
2. استكمال توحيد نصوص الواجهة القديمة التي ما زالت تعرض «مشتري/بايع»: صفحة مراجعة نشاط الأدمن، لوحة مالك النشاط، الثقة، من نحن، المساعدة، الأسئلة الشائعة، بعض الإدارة والتصدير. استخدم ملفًا واحدًا لكل patch ولا تغيّر المفاتيح.

4. استكمال E2E لمسار الأدمن: إنشاء بلا مالك ومع مالك اختياري، الصور والـrollback، المسودة والنشر، البحث والصفحة العامة. اختبر كذلك الطلبات الداخلية منفصلة عن واتساب والطابور دون اتصال وخصوصية Service Worker.
5. مراجعة الأسرار القديمة في Git history وخطة تدويرها مع مالك المشروع؛ لا تعرض القيم الحساسة في logs أو docs.
