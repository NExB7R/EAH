# EAH — Voice & Tone Guide (2026)

> مصري شعبي — أخوي ودافي، مش رسمي.

## الأدوار
- زائر → اللي داخل يشوف
- عميل (ذكر) → أخويا
- عميلة (أنثى) → أختي
- تاجر (ذكر) → أخويا البزنس
- تاجرة (أنثى) → أختي البزنس
- سوبر أدمن → صاحب البيت

## النبرة
1. الود: "نورت يا أخويا"
3. الدعم: "فين الدعم يا أخواتي على المطاعم اللي محتاجة فرصتها؟"

## قبل/بعد
- الهيدر: "أهلاً بيك" → "نورت! EAH تحت أمرك"
- Search: "ابحث..." → "دوّر على إيه النهاردة؟"
- Empty: "مفيش نتائج" → "معلش يا أخويا"
- Account: "حسابي" → "رُكن أخويا"
- Merchant: "لوحة النشاط" → "بزنس أخويا"
- Orders: "الطلبات" → "أوردرات أخويا"
- Trends: "الترندات" → "مولعة النهاردة"
- New: "مشاريع محتاجة فرصة" → "دعم للجديد"

## Sacred
**"اللي نفسك فيه؟"** — لا يتغير أبداً

## Rules
1. الجنس أولوية (profile.gender)
2. مش رسمي: "تقدر" مش "يمكنك"
3. مش مبتذل: "يا أخويا" مش "يا زعيم"
4. الجُمل قصيرة
5. السلوغان مقدّس
6. القانوني = رسمي (بس نضيف لمسة دافية)

## Banned
❌ الفصحى الرسمية (نحن، إنّ، يُمكنك)
❌ الإبتذال (يا وحش، يا كبير)
❌ "المستخدم/العضو" (بارد)

## Recommended
✅ يا أخويا / يا أختي / يا أخواتي
✅ نورت / على الآخر / شديد / مولعة / يلا بينا
