## 🔴 أولوية قصوى (الأسبوع الجاي)

### 1. AI Search ذكي (تحسين `smartSearch` الحالي)
- **المشكلة:** البحث الحالي بدائي — كلمة كاملة بس
- **الحل:**
  - Word-level matching (مش بس كامل)
  - Fuzzy matching (typos)
  - Ranking متعدد (rating + trust + distance)
  - Synonyms مصري موسّع (200+ كلمة)
  - تطبيع أرقام عربية (٠-٩ → 0-9)
- **التكلفة:** مجاني
- **الوقت:** 6 ساعات

### 2. Voice Search ذكي جداً
- **إيه:** Whisper مجاني (Supabase) → بحث فوري
- **الفهم:** "عايز حاجة حلوة قريبة مني" → يفهم: مطعم حلو + قريب
- **الوقت:** 3 أيام
- **الميزة:** تفهم العامية + اللهجات المحلية

### 3. Voice/Image/File في الطلبات
- **إيه:** OrderModal يقبل:
  - كتابة
  - رفع صورة
  - تسجيل صوتي
  - **screenshot من المنيو** (ميزة جديدة)
- **الوقت:** 4 أيام

### 4. Menu Slider + Screenshot
- **إيه:** في OrderModal → زر "شوف المنيو"
- **Slider:** سلس + خفيف + مطابق للستايل
- **Screenshot:** المستخدم ياخد صورة من المنيو → تتضاف للطلب
- **الوقت:** 4 ساعات

### 5. Fraud Detection شامل
- **المشكلة:** ناس مؤذية بتحاول تخرب
- **المستويات:**
  - **بسيط:** منع تقييم النفس (موجود ✅)
  - **متوسط:** velocity checks (10+ تقييم/ساعة → flag)
  - **متقدم:** AI يحلل نمط السلوك → يحظر تلقائي
  - **قوي:** Device fingerprint + IP tracking
- **الأماكن:**
  - التعليقات + التقييمات
  - الترند + النقاط
  - الإعلانات + المدفوعات
  - الطلبات + الاستخدام
- **الوقت:** أسبوع

### 6. Smart Notifications (مش بطريقة تمنع الجدد)
- **إيه:** AI يرشح حسب ذوق المستخدم
- **الجديد:** لحد ما يفهم ذوقه (10+ تفاعلات) → يشوف كل حاجة
- **بعد كده:** إشعارات مخصصة
- **الوقت:** 5 أيام

### 7. System Health Monitor
- **إيه:** "🔴 خطأ في /businesses/X" على واتساب
- **التفاصيل:**
  - مراقبة الأخطاء تلقائي
  - إرسال تقرير مجمّع كل ساعة
  - شرح مبسط للمشكلة
  - اقتراح حل
- **الوقت:** يومين

## 🤖 Telegram Bot (تصور كامل — مؤجل)

### 3 بوتات في بوت واحد:
- **Admin Bot** (إنت) — إشعارات + موافقات + تقارير
- **Merchant Bot** (التجار) — إشعارات طلبات + ردود
- **Client Bot** (العملاء) — بحث + إشعارات + مساعد

### التحقق (3 فحوصات):
1. **ID = Admin?** ← من `.env.local` (server-only)
2. **ID مربوط بتاجر?** ← من DB (Yes/No فقط)
3. **غير كده** ← عميل عادي

### إدارة الأدمن:
- **الآن:** `.env.local`
- **بعدين:** جدول `telegram_admins` + `/admin/telegram` UI

### كـ ميزة مدفوعة:
- **للتاجر:** حسب الباقة (مجاني = أساسي | شراكة = كل حاجة)
- **للعميل:** حسب النقاط أو دفع مباشر
- **الترقية من البوت** = قناة بيع

### أمان:
- Bot Token: `.env.local` (server-only)
- Chat IDs: مش بتنكشف
- RLS يفضل 100%
- Service Role: بحذر شديد

### أولويات البوت (لما نبدأ):
1. Admin Bot (3 ساعات)
2. Merchant Bot (5 ساعات)
3. Client Bot (5 ساعات)
4. Mini App (أسبوعين — مؤجل)

### ⚠️ مبدأ مهم:
**البوت بوابة للموقع — مش بديل.**
- كل إشعار → زر "افتح في EAH"
- ملخص في البوت، تفاصيل في الموقع
- الإعلانات + الباقات = في الموقع بس
