## 13. دورة النشاط من الإنشاء إلى الظهور العام

- [ ] الأدمن ينشئ نشاطًا من غير مالك مرتبط، ويظل `owner_profile_id = null` من غير ما يمنع ذلك النشر.
- [ ] يتم توضيح أن رقم الاتصال الأساسي المطلوب حاليًا هو رقم **النشاط**، وليس رقم المالك الشخصي.
- [ ] النشاط المنشور يظهر في `/explore` ونتائج البحث والرابط العام `/businesses/[slug]`.
- [ ] الكارد يعرض الغلاف/بديله، الاسم، النوع، المنطقة، الحالة، التقييم الحقيقي فقط إن وجد، وقنوات الطلب المفعّلة فقط.
- [ ] صفحة النشاط تعرض العنوان والمواعيد والفروع والصور والعروض والمراجعات المتاحة، من غير تسريب أرقام الهاتف الخاصة في HTML العام.
- [ ] اختيار حساب مشتري كمالك يحوّله إلى دور البايع بنجاح؛ حساب البايع الحالي يظل بايعًا. لا يمكن ربط نشاط بحساب أدمن.
- [ ] البايع المرتبط فقط يقدر يدير النشاط، وأي مستخدم آخر لا يستطيع تعديل النشاط عبر الـ Server Actions أو API.
- [ ] رفع الغلاف والشعار والمعرض يتحقق من نوع الملف وحجمه ومصدره، وتظهر الصورة في صفحة النشاط بعد الحفظ وإعادة التحقق من الكاش.
- [ ] فشل حفظ جهة اتصال أو ترقية المالك لا يترك نشاطًا جزئيًا غير واضح؛ يتم التراجع عند الإمكان وتسجيل التفاصيل داخليًا.
- [ ] نشاط البايع المقدم للمراجعة لا يظهر علنًا قبل موافقة الأدمن، بينما نشر نشاط الأدمن لا يعتمد على وجود مالك.
- [ ] اختبار دورة الطلب منفصل عن النشر العام: النشاط غير المملوك يظل قابلًا للاكتشاف، لكنه لا يستقبل طلبات داخل المنصة.
- [ ] تنفيذ السيناريوهات السابقة بحسابات اختبار غير إنتاجية ثم تسجيل نتيجة كل سيناريو قبل الإطلاق.

## 14. ترتيب التعامل مع فشل الفحوص

1. إذا كان Vercel يذكر أخطاء TypeScript أو build، أصلح السبب ثم أعد بناء نفس الـ commit وراجع سجل TypeScript.
2. إذا كان GitHub Actions يفشل مع `runner_id: 0` وبدون خطوات، سجّلها كعطل runner/حساب في [issue #22](https://github.com/NExB7R/EAH)؛ لا تعتبره نجاحًا ولا تنسبه تلقائيًا للكود.
3. إذا فشل اختبار RLS قبل إعداد `SUPABASE_DB_URL`، استخدم قاعدة اختبار غير إنتاجية ولا تضع بيانات اتصال في السجلات.
4. لا تطبق Migration على الإنتاج قبل مطابقة تاريخ المايجريشن بين المستودع وقاعدة البيانات، ونسخة احتياطية قابلة للتحقق وخطة rollback مراجعة.
5. لا تُدمج تغييرات الإصدار لمجرد أن المعاينة `READY`; يلزم اكتمال اختبارات الأدوار والرفع والنشر والبحث والصفحة العامة.

- [ ] «ماركت» متاح في اختيارات الأدمن، تقديم البايع، تعديل البايع، فلتر الاستكشاف، عنوان النتائج والعداد، البحث الذكي والمرادفات.
- [ ] فلتر النوع يضيف `type=supermarket` للرابط، ويعيد النتائج الصحيحة عند التحديث أو مشاركة الرابط.
- [ ] عند تقديم نشاط مع GPS، تُحفظ إحداثياته في `business_locations` ويظهر الموقع في الخريطة وشارة المسافة والبحث القريب.
- [ ] رقم واتساب المستخدم في القناة العامة هو نفس الرقم المخزن في `business_contact_methods`; إذا لم يدخل البايع رقمًا مختلفًا، يُستخدم رقم النشاط الرئيسي وفق تسمية الحقل.
- [ ] اختيار «أنشطة أخرى» في طلب البايع يفرض اسمًا مخصصًا ويخزن `business_type_status='pending'`; لا يظهر الاسم المخصص حتى اعتماد الأدمن.
