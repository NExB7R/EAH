# EAH — استراتيجية الإطلاق الاحترافية (Zero-Defect Launch Strategy)

> **الهدف:** إطلاق منصة بمستوى عالمي (World-Class)، قابلة للتوسع من شبين القناطر لمصر كلها.
> **المنهجية:** التنفيذ المبني على التبعيات (Dependency-Driven). لا ننتقل لمرحلة إلا بعد قفل التي قبلها 100%.

---

## المرحلة 0: البنية التحتية والأمان (Infrastructure & Security)
> **الهدف:** ضمان بيئة عمل مستقرة، آمنة، وجاهزة للـ CI/CD بدون أي تسريبات.
- [x] تنظيف Git History (إزالة التوكنات).
- [x] تأمين الـ RLS (15/15 جدول).
- [x] حماية بيانات التواصل (Contact Privacy).
- [x] تثبيت قواعد الدستور (CONSTITUTION.md).
- [ ] تثبيت بيئات العمل (Vercel Environments: Development vs Production).

## المرحلة 1: لوحة الإدارة (Admin Core)
> **الهدف:** الأدمن هو "العقل المدبر". لازم يكون قادر يضيف وينشر الأنشطة بدقة قبل أي حاجة.
- [ ] اختبار مسار إضافة نشاط جديد (Wizard): الخطوات، رفع الصور، تحديد الموقع.
- [ ] اختبار ربط الأنشطة بالحسابات (Owner Linking) وصلاحياتها.
- [ ] اختبار دورة حياة النشاط (مسودة -> مراجعة -> منشور -> مرفوض).
- [ ] اختبار إدارة المستخدمين (تغيير الأدوار، تعليق الحسابات).

## المرحلة 2: لوحة التاجر (Merchant Core)
> **الهدف:** التاجر هو "العميل الأول". تجربته لازم تكون أسهل من فيسبوك.
- [ ] اختبار تسجيل الدخول وإكمال الملف الشخصي.
- [ ] اختبار إدارة النشاط: المنيو، الفروع، أوقات العمل، العروض.
- [ ] اختبار نظام الطلبات (Orders v2) واستلام الإشعارات.
- [ ] اختبار الإحصائيات (Insights) وتقارير الأداء.

## المرحلة 3: إضافة الأنشطة الحقيقية (Seeding & Data Entry)
> **الهدف:** المنصة فارغة بدون بيانات. هندخل أول 10-20 نشاط حقيقي لتجربة الواجهة.
- [ ] إدخال بيانات حقيقية (أسماء، صور، أرقام، مواقع).
- [ ] التأكد من ظهور الأنشطة في البحث (Explore) بشكل صحيح.
- [ ] التأكد من دقة المعلومات وعدم وجود أخطاء إملائية.

## المرحلة 4: الواجهة الأمامية والتجاوب (Public UI & Mobile-First)
> **الهدف:** تجربة المستخدم (العميل) هي واجهة المشروع. لازم تكون مبهرة على الموبايل.
- [ ] مراجعة الصفحة الرئيسية (Hero, Featured, Categories).
- [ ] مراجعة صفحة الاستكشاف (الفلاتر، البحث، الترتيب).
- [ ] مراجعة صفحة النشاط (المنيو، التقييمات، كشف الأرقام).
- [ ] اختبار التجاوب (320px, 375px, 390px, 414px) وإصلاح أي Horizontal Scroll.
- [ ] مراجعة الـ Dark Mode، الـ Typography، وحركات الـ Animation.

## المرحلة 5: الجودة، الأداء، والـ SEO (Quality & Performance)
> **الهدف:** مشروع يفتح في ثانية، ويظهر في أول نتائج جوجل.
- [ ] تحسين سرعة التحميل (Lighthouse: Performance > 90).
- [ ] مراجعة الـ Core Web Vitals.
- [ ] إعداد الـ SEO (Sitemap, Robots.txt, Meta tags, JSON-LD).
- [ ] تفعيل الـ PWA (التثبيت على الشاشة الرئيسية، إشعارات الـ Push).
- [ ] اختبار الوصول (Accessibility / A11y) - التنقل بالكيبورد.

## المرحلة 6: الإطلاق الرسمي (Go-Live)
> **الهدف:** فتح الأبواب للجمهور.
- [ ] ربط الدومين النهائي (Custom Domain).
- [ ] عمل Backup كامل لقاعدة البيانات.
- [ ] تحويل الريبو لـ Private (لما نضمن الـ Actions).
- [ ] الإطلاق الإعلاني (Social Media, Local Outreach).

## المرحلة 7: المدفوعات والاشتراكات (Monetization) — مؤجلة
> **الهدف:** تحقيق الدخل بعد إثبات نجاح المنصة (Product-Market Fit).
- [ ] دمج بوابة دفع (Paymob / Fawry).
- [ ] تفعيل باقات التاجر (Basic, Premium).
- [ ] نظام الإعلانات المدفوعة.
