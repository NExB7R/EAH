# EAH — خطة الإطلاق (Launch Plan)

> **الحالة:** قيد التنفيذ. كل خطوة تتقفل لازم تتسجل في `PROGRESS.md`.
> **القاعدة:** Mobile-First إجباري. المدفوعات في النهاية (بعد الإطلاق).

## المرحلة 1: التصميم والتجاوب (UI/UX & Responsiveness)
- [ ] مراجعة واجهة المستخدم (Public Pages) على Vercel.
- [ ] التأكد من التجاوب على الموبايل (320px, 360px, 390px).
- [ ] إصلاح أي مشاكل في الـ CSS (Horizontal Scroll, Broken Modals, Touch Targets).
- [ ] مراجعة الـ Dark Mode والهوية البصرية (Neon).

## المرحلة 2: لوحة الأدمن (Admin Dashboard)
- [ ] التأكد من عمل مسار إضافة نشاط جديد (Wizard) من الألف للياء.
- [ ] مراجعة إدارة الأنشطة (Publish, Reject, Link Owner).
- [ ] مراجعة إدارة المستخدمين والصلاحيات.

## المرحلة 3: لوحة التاجر (Merchant Dashboard)
- [ ] التأكد من تسجيل الدخول وإنشاء الحساب.
- [ ] مراجعة إدارة المنيو، الفروع، وأرقام التواصل.
- [ ] مراجعة إدارة الطلبات (Orders v2) واستقبال الإشعارات.
- [ ] مراجعة إعدادات التاجر (أوقات العمل، العروض).

## المرحلة 4: رحلة العميل (Customer Journey)
- [ ] مراجعة البحث والفلترة (Explore).
- [ ] مراجعة صفحة النشاط (Business Detail) وكشف الأرقام (Contact Reveal).
- [ ] مراجعة التقييمات والتفاعل (Reviews, Follow, Favorites).
- [ ] مراجعة تجربة الطلب (In-app Orders) إن وجدت.

## المرحلة 5: الجودة والأداء (QA & Performance)
- [ ] التأكد من خلو الكود من أخطاء TypeScript (CI شغال).
- [ ] مراجعة سرعة التحميل (Lighthouse).
- [ ] التأكد من الـ SEO (Sitemap, Robots.txt, Meta tags).

## المرحلة 6: الإطلاق (Launch)
- [ ] إضافة أول نشاط حقيقي (Real Business).
- [ ] تجربة كاملة من متصفح حقيقي وموبايل حقيقي.
- [ ] الإطلاق للجمهور!

## المرحلة 7: المدفوعات (Payments) — مؤجلة
- [ ] دراسة بوابات الدفع المناسبة لمصر (Paymob, Fawry).
- [ ] تفعيل نظام الاشتراكات للتجار.
