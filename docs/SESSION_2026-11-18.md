## Bugs found + fixed

### Bug 1: SIGILL libvips
- **الأعراض:** `next-server` يختفي فجأة، لا رسالة
- **السبب:** `sharp` + `libvips` معمارية CPU غير متوافقة
- **الحل:** `images.unoptimized: true` (Cloudinary مسؤول التحسين)
- **تحقق:** `dmesg` يُظهر `traps: next-server trap invalid opcode in libvips`

### Bug 2: CSP-VIOLATION eval
- **الأعراض:** JS لا يعمل، FloatingCapsule لا يظهر
- **السبب:** `script-src-elem` فقط، `script-src` مفقود
- **الحل:** إضافة `script-src` صريح
- **تحقق:** `[CSP-VIOLATION] { directive: 'script-src', blocked: 'eval' }` يختفي

- **الأعراض:** offline queue flush يفشل (404)
- **السبب:** حذف بالخطأ في `070ebd6` (خشية حذف `/offline` page)
- **الحل:** `app/api/offline/flush/route.ts` (132 سطر، idempotent)
- **تحقق:** `queue.ts:58` fetch نجح

### Bug 4: Service Role Key placeholder
