## 🎯 إيه EAH؟

منصة بتوصّل أهل شبين القناطر والقرى المجاورة بأماكنهم المحلية:

- **مطاعم** • **صيدليات** • **ماركت** • **توصيل** • **أنشطة أخرى**
- بحث ذكي باللهجة المصرية
- طلب مباشر على واتساب (بدون وسيط، بدون عمولة)
- تجربة عربية أصلية، نيون ناعم، dark-only

**المميز:** مجانية بالكامل للمشتري، بدون عمولة على البايع.
